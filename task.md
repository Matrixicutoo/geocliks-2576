# Scratchpad

## SEO pass — geocliks.com — ✅ COMPLETE (2026-09-13)

All seven approved items shipped.

1. **Per-page meta** — `src/web/lib/seo.ts` (`useSeo`, `useNoindex`, `useRobots`,
   `SITE_URL`, `absoluteUrl`) sets title, description, canonical, og:*/twitter:*
   and JSON-LD per route and restores the previous values on unmount. Copy lives
   in `src/web/lib/seo-copy.ts` (`SEO_DESCRIPTIONS`, English only — crawlers index
   the default locale). Wired into: `index`, `get-app`, `help`, `help-category`,
   `help-article`, and both legal pages via `components/legal-page.tsx`
   (`description` + `path` are now required props).
2. **robots.txt** — `public/robots.txt`. Disallows the private/token paths,
   explicitly allows `/pricing` (it redirects to `/#pricing`), points at the sitemap.
3. **sitemap.xml** — generated by `scripts/gen-sitemap.ts` from the static paths plus
   the live help catalog (`help/resolve.ts`); 72 URLs. Wired into `bun run build`, so
   it regenerates whenever the help content changes. No `changefreq`/`priority`/
   `lastmod` on purpose (Google ignores the first two; a fake `lastmod` is worse
   than none).
4. **Canonical + og:url** — set per route by `useSeo`, absolute against
   `https://geocliks.com`. Deliberately NOT in `index.html`: a static canonical there
   would point every route at `/`.
5. **Structured data** — `src/web/lib/structured-data.ts`: Organization +
   SoftwareApplication on `/`, BreadcrumbList on the help tree, FAQPage on help
   categories that have Q&A, TechArticle on help articles.
6. **Images** — resized + recompressed the five oversized sample JPEGs in place
   (`public/images` 4.6M → 3.9M; `crew-collage.jpg` 786K → 252K). `fetchPriority="high"`
   on the two above-the-fold heroes, `loading="lazy" decoding="async"` on the rest of
   the public-page `<img>` tags. WebP was measured and rejected — for these photos it
   came out larger than JPEG at matched quality. Behind-auth/dynamic images untouched.
7. **website.config.json** — placeholder name/description/url replaced with the real
   ones. `hostname`/`port` left alone. Note: nothing in this repo reads this file, so
   the edit may only matter at a deploy stage not visible here.

### Prerendering — NOT possible, substituted

`src/web/src/__server.ts` is template-managed and resolves every request with
`Bun.file(path).exists()`, falling back to the single root `dist/index.html`.
Verified empirically that `Bun.file(dir).exists()` is `false` for a directory even
when `dir/index.html` exists, so a prerendered `dist/pricing/index.html` would never
be served. Runtime meta injection is the substitute: Googlebot renders JS and indexes
it; the static tags in `index.html` remain the default for non-JS social unfurlers
(`og:image`/`twitter:image` made absolute, `og:locale` added for that reason).
